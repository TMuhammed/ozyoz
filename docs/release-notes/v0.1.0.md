## Özyoz 0.1.0 — birinçi nashr

Eski usulda yozasiz, yangi alifboda çiqadi: **sh→ş, ch→ç, oʻ→ö, gʻ→ğ**. Hammasi lokal, heç narsa serverga yuborilmaydi. Qoidalar O‘RQ-1184-son Qonun (21.10.2026) asosida; yangi alifbo 2027-yil 22-apreldan kuçga kiradi.

### Brauzer kengaytmasi (Chrome, Edge, Yandex)
- `ozyoz-0.1.0.zip` — doʻkonlarga yuklanadigan paket. Qoʻlda oʻrnatiş: `chrome://extensions` → Developer mode → Load unpacked → arxivdan çiqarilgan papka.
- Matn maydonlari, textarea va contenteditable; Ctrl+Z eski yozuvni qaytaradi; paste ham ötkaziladi; parol va karta maydonlari oʻzgartirilmaydi.
- Manzil qatorida `uz` + matn — yangi alifbodagi soʻrov bilan qidiradi.

### Kompyuter uçun (barça dasturlarda yoziş)
| Tizim | Fayl | Eslatma |
|---|---|---|
| macOS 12+ (Apple Silicon va Intel) | `Özyoz_0.1.0_universal.dmg` | Birinçi oçişda: oʻng tugma → Open (imzolanmagan). System Settings → Privacy & Security → **Accessibility** da Özyoz ni yoqing. |
| Windows 10/11 | `Özyoz_0.1.0_x64-setup.exe` yoki `.msi` | SmartScreen ogohlantirişi: More info → Run anyway (imzolanmagan). |
| Linux (X11) | `.deb`, `.rpm`, `.AppImage` | Wayland qoʻllab-quvvatlanmaydi — kiriş oynasida X11 seansini tanlang. |

Terminal, kod muharrirlari va parol menejerlari sukut boʻyiça oʻçirilgan; roʻyxat sozlamalarda.

### Safari
Xcode loyihasi `safari/` papkasida; App Store nashri keyingi bosqiçda.

**Русский.** Первый выпуск Özyoz: расширение для Chrome, Edge и Яндекс.Браузера и приложение для macOS, Windows и Linux, которое конвертирует узбекскую латиницу в новый алфавит прямо во время набора. Всё работает локально. На macOS нужно разрешение Accessibility, на Linux только X11. Установщики не подписаны: при первом запуске macOS и Windows покажут предупреждение.

**English.** First release of Özyoz: a browser extension (Chrome, Edge, Yandex) and a desktop app (macOS, Windows, Linux) that convert Uzbek Latin text to the 2026 alphabet as you type. Everything runs locally. Installers are unsigned for now; macOS needs the Accessibility permission; Linux requires X11.

Hisobot va takliflar: https://github.com/TMuhammed/ozyoz/issues
